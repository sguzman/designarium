# Designarium stewardship

- Keep public gallery development autonomous; do not require routine human QA.
- Push direct commits to main; use the native GitHub Pages branch deployment for publication and GitHub Actions for browser QA.
- Preserve approved imagery and its source/provenance. Never overwrite a liked
  concept without archiving the previous version.
- Designarium is aesthetic reference, not a GUI renderer or functional app.
- Separate every project's composition and information architecture.
- No private conversation content or confidential Taria resources in commits.
- Favor the simplest accessible and responsive static site. No paid services.
- When changing images, preserve full-resolution originals and optimize assets.
- Verify GitHub Pages deployment before claiming that the live URL works.
